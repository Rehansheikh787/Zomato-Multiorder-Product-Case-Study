# User Stories

## P0 — Multi-Restaurant Cart

### US1 — Add Items from Another Restaurant
As a family member, I want to add food from another eligible nearby restaurant to my existing cart so that I can order different food preferences together.

### US2 — Review Items by Restaurant
As a customer, I want to see all selected items grouped by restaurant in my cart so that I can verify what I am ordering before checkout.

### US3 — Modify Items Without Losing Other Selections
As a customer, I want to change or remove an item from one restaurant without losing items from other restaurants so that I can correct my order without starting again.

### US4 — View Multi-Restaurant Eligibility
As a customer, I want to know which nearby restaurants can be included in my multi-restaurant order so that I do not select food that cannot be ordered together.

## P1 — Single Checkout

### US5 — Review Multi-Restaurant Order
As a customer, I want to review all selected items from my restaurants in one checkout so that I can confirm my order before paying.

### US6 — View Final Payable Amount
As a customer, I want to see the total payable amount including applicable fees and discounts so that I know exactly what I will be charged before payment.

### US7 — Pay for All Orders Together
As a customer, I want to pay for my selected restaurant orders in one payment step so that I do not have to complete separate payments for each restaurant.

### US8 — Recover from Payment Failure
As a customer, I want to retry a failed payment without rebuilding my multi-restaurant order so that I can complete my order without starting over.
