# Jira Setup

The execution backlog was organized using two epics and eight stories.

## Epic hierarchy

### P0 — Multi-Restaurant Cart
- SCRUM-5 — US1 Add Items from Another Restaurant
- SCRUM-6 — US2 Review Items by Restaurant
- SCRUM-7 — US3 Modify Items Without Losing Other Selections
- SCRUM-8 — US4 View Multi-Restaurant Eligibility

### P1 — Single Checkout
- SCRUM-9 — US5 Review Multi-Restaurant Order
- SCRUM-10 — US6 View Final Payable Amount
- SCRUM-11 — US7 Pay for All Orders Together
- SCRUM-12 — US8 Recover from Payment Failure

The parent epics are:
- SCRUM-13 — P0 Multi-Restaurant Cart
- SCRUM-14 — P1 Single Checkout

## What is captured on each story

Each Jira story contains:
- final user story
- capability
- PM-provided size
- PM-provided risk
- PM-provided impact
- approved acceptance criteria where available
- an explicit note when acceptance criteria are still open

Priority labels represent the capability sequence: P0 is represented above P1.

> Private Jira workspace URLs and account details are intentionally excluded from this public portfolio.
