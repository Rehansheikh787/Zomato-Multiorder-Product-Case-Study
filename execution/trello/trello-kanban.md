# Trello Kanban

A separate project board was created to visualize operational flow without changing the approved product requirements.

## Board workflow

1. Project Control
2. Product Backlog
3. Ready for Development
4. In Progress
5. Blocked / At Risk
6. QA / UAT
7. Done
8. Risks & Decisions

## Product Backlog

The Product Backlog contains the same eight stories used in Jira, with:
- Jira reference
- capability
- size
- risk
- impact
- final user-story statement
- approved acceptance criteria where available

Stories without finalized acceptance criteria are explicitly marked as open rather than being filled with assumed requirements.

## Project Control

The board includes control cards for:
- project scope
- locked Size / Risk / Impact inputs
- Jira story mapping

## Risks & Decisions

Dedicated tracking is used for:
- US3 high delivery risk
- US7 payment complexity
- US8 payment recovery
- undefined Total formula
- remaining acceptance criteria
- undefined performance target

> The live Trello board is private. This document shows the portfolio-safe structure without exposing private workspace details.
